# Finance Tracker

This is a simple finance tracking web application built with Django.

I made this project to practice backend development with Django and work with authentication, databases, forms, APIs and deployment.

## Features

- User registration and login
- Add income and expense transactions
- Create and manage categories
- Default categories for new users
- Monthly budgets
- Category budgets
- Search and filter transactions
- Import transactions from CSV
- Dashboard with basic financial statistics
- REST API for transactions

## Technologies

- Python
- Django
- Django REST Framework
- PostgreSQL
- SQLite
- Bootstrap
- Chart.js
- Gunicorn
- Railway
